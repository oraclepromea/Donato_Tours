# Donato Tours - Modern Website

A modern, professional website for Donato Tours, a tour company specializing in Amazon rainforest and pampas tours in Bolivia.

## 🌿 About Donato Tours

Donato Tours offers unforgettable adventures in Bolivia's Amazonian region, including:

- **Madidi National Park** - Guided trekking and wildlife observation
- **Pilon Lajas Biosphere Reserve** - Rafting through Bala Canyon
- **Pampas Adventures** - Fishing, swimming, and horse riding in the Yacuma River region

## ✨ Website Features

### Modern Design
- Responsive, mobile-first design
- Nature-inspired color palette with earth tones
- Professional typography using Inter and Playfair Display fonts
- Smooth animations and transitions
- Clean, inviting layout

### Interactive Elements
- Fixed navigation with scroll effects
- Mobile hamburger menu
- Smooth scrolling between sections
- Contact form with validation
- Hover effects and animations
- Scroll-to-top functionality

### Sections
- **Hero Section** - Compelling introduction with call-to-action buttons
- **About Section** - Company overview with feature highlights
- **Tours Section** - Three main tour packages with detailed descriptions
- **Gallery Section** - Photo showcase (placeholder for actual images)
- **Contact Section** - Contact information and inquiry form
- **Footer** - Additional links and company information

## 🚀 Getting Started

### Prerequisites
- A modern web browser
- Basic web server (optional, for local development)

### Installation
1. Clone or download the project files
2. Open `index.html` in your web browser
3. For local development, use a simple HTTP server:
   ```bash
   # Using Python 3
   python -m http.server 8000
   
   # Using Node.js (with http-server package)
   npx http-server
   
   # Using PHP
   php -S localhost:8000
   ```

## 🔧 Customization

### Adding Real Images
Replace the placeholder gallery items with actual tour photos:
1. Add images to the `assets/images/` folder
2. Update the gallery section in `index.html`
3. Modify CSS background images in `style.css`

### Contact Form Integration
To make the contact form functional:
1. Set up a backend service (PHP, Node.js, etc.)
2. Update the form action in `index.html`
3. Modify the JavaScript form handler in `script.js`

### Content Updates
- Tour descriptions can be updated in the tours section of `index.html`
- Contact information is located in both the contact section and footer
- Company information can be modified in the about section
